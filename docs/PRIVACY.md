# Privacy

Frontier Decision Engine is browser-local by default. The public application has no backend, account system, analytics, telemetry, cookies, remote AI provider, or default upload endpoint.

Guided framing uses tab-scoped session storage to recover in-progress framing after an accidental refresh. Decision Lab uses bounded browser autosave for structured work and, after a re-record, bounded local history for prior valid Decision Receipt v2 records. Clearing the current draft does not erase that historical receipt store. Browser-local storage is not encrypted confidential storage.

Local decision files are processed in the browser. Do not enter information that requires an approved confidential, controlled, or otherwise restricted environment.

Public examples must not contain personal, client, confidential source-research, or unpublished internal material.


## Public pilot handling

The public deployment is suitable only for public or sanitized decision material. Do not enter proprietary, confidential, controlled, classified, export-restricted, or otherwise restricted information unless the execution and storage environment has been separately approved for that information.

The interface does not provide a control that can elevate the public deployment into a private or restricted environment. Higher handling classes require a separately governed deployment.

## Pilot measurement

The Pilot Proof Envelope is a separately exported research artifact. FDE does not silently collect pilot responses, usage analytics, session replay, or customer decision data.
