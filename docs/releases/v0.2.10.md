# Frontier Decision Engine v0.2.10

Frontier Decision Engine v0.2.10 is the immutable historical initial public release. The artifact was frozen on July 29, 2026 and published publicly on July 30, 2026.

- **Windows manifest-path correction:** the manifest builder uses `fileURLToPath()` rather than URL `.pathname`, preserving valid drive-letter paths in Git Bash and Windows Node.
## Highlights
- Decision-first DMDU workflow with XLRM framing, plural non-probabilistic futures, strategy-specific stress testing, critical-objective gating, adaptive pathways, and mandatory human rationale.
- Open Phenomenon Verification application profile with local hashing, transparent calibration and measurement, Evidence Level 0–2 controls, and portable JSON/HTML exports.
- Public-safe morphology, experience, and reference datasets with strict evidence-class and privacy boundaries.
- Automated Node, repository, browser, accessibility, reflow, forced-colors, PDF, and deterministic-packaging gates. The current discovered test count is generated in `project-facts.json`.
- GitHub Pages workflow implementation for live HTTPS end-to-end verification.
- Production Release workflow implementation for signed annotated tags, immutable-release checks, deterministic artifacts, attestations, and hosted verification.
## Delivery evidence boundary

Public workflow history shows that the production Release workflow was not exercised for v0.2.10. The signed-tag, attestation, immutable-release-precheck, and hosted-verification controls are implemented in the repository but are not completed workflow evidence for this historical release.
## Maturity boundary

This is a public reference implementation for education, collaboration, methodology review, and controlled partner demonstrations. It is not yet a dependable general-purpose tool or external-user pilot platform. Scores are analyst inputs rather than probabilities. Machine output is advisory. The project is not a predictive engine, a full RDM/MoRDM ensemble, scientific proof of phenomenon origin, or a sole basis for irreversible decisions.
