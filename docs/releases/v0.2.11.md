# v0.2.11

Frontier Decision Engine v0.2.11 presents one clear, browser-local Decision Lab
for structured choices under deep uncertainty.

## Highlights

- A beginner-first homepage, walkthrough, and six-step working interface.
- A ready synthetic critical-material source-qualification reference case.
- Browser-local autosave, validated decision-file reopening, and readable exports.
- Explicit invalid, incomplete, tie, vulnerability, and human-decision states.
- Responsive navigation, system/light/dark appearance, keyboard operation,
  reflow, forced-colors, and print verification.
- Seventy automated Node tests, repository validation, six real-browser modes,
  deterministic packaging, signed-tag enforcement, attestations, and hosted
  release-asset verification.

## Compatibility and boundary

The application version is 0.2.11 and retains the compatible decision schema
version 0.2.10. The synthetic reference case does not certify a supplier,
qualify a material, confirm capacity or compliance, predict prices, recommend
an investment, or replace accountable human judgment.
