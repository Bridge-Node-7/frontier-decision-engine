# v0.3.0

## Human-governed decision synthesis

Application version is 0.3.0. The compatible decision schema 0.2.10 remains available alongside the explicitly versioned 0.3.0 schema.

This release candidate adds the compatible `0.3.0` decision schema and presents Decision posture, the strongest tested alternative, and the recorded human decision as distinct outputs. A shared deterministic synthesis supports the on-screen executive signature and readable Decision Brief.

### Changes

- Adds Four-P criteria and explicit evidence, requirement, condition, safeguard, monitoring, and reassessment semantics.
- Adds progressive disclosure for decision dimensions and Brief, Review, and Inspect projections.
- Adds truthful normalized-value traceability without implying an arithmetic conversion.
- Strengthens browser-local information-boundary language and the useful no-JavaScript path.
- Preserves the `0.2.10` decision schema alongside `0.3.0`.

### Evidence boundary

FDE provides transparent software decision support. It does not approve, authorize, certify, qualify, consent, or make an investment decision. Public examples are synthetic; people retain decision authority.
